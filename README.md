# 🎲 Dice Roller

A simple **Dice Roller program built using Python**.
The program allows the user to roll a dice and generates a random number between **1 and 6**.

## 📌 Features

* 🎲 Roll a dice
* 🔢 Generates a random number from 1 to 6
* 🔄 Roll the dice multiple times
* 🚪 Exit option
* ❌ Handles invalid choices

## 🛠️ Technologies Used

* Python
* `random` module

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/dice_roller.git
```

3. Open the project folder:

```bash
cd dice_roller
```

4. Run the program:

```bash
python dice_roller.py
```
