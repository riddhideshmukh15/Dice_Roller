# 🎲 Dice Roller

## 📌 About the Project
Dice Roller is a simple Python project that simulates rolling a six-sided dice. Users can roll the dice multiple times using the roll-again feature or exit the game whenever they want.

## ✨ Features
- 🎲 Generates a random number between 1 and 6.
- 🔄 Roll again option to roll multiple times.
- 🎮 Simple menu-driven interface.
- ✅ Input validation for invalid choices.
- 🚪 Exit option to end the game.

## 🛠️ Technologies Used
- Python
- Random Module
- While Loop
- If-elif-else Statements
- User Input Handling

## 🎯 Learning Outcomes
- Understanding loops and conditional statements.
- Using Python's built-in `random` module.
- Practising nested loops and `break` and `continue`.
- Handling user input and invalid choices.
